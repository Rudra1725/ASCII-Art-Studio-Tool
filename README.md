# ASCII-Art-Studio-Tool
A tool built with Python and Tkinter that generates ASCII art banners and automatically formats them for clipboard copy across multiple social and messaging platforms.


Features
Instant Generation: Type any text and convert it instantly using popular retro ASCII fonts.

Multiple Font Presets: Includes block, standard, slant, banner, isometric1, digital, caligraphy, and more.

Platform-Optimized Formats:

WhatsApp: Wraps outputs with triple backticks (```) to enforce monospaced rendering in chats.

Instagram: Pads spaces with invisible braille characters (⠀) and line dividers so captions and comments keep their shape instead of collapsing.

Discord: Formats output in a syntax-highlighted code block (```text).

X (Twitter): Clean raw output tailored for quick tweets and replies.

One-Click Clipboard: Instant copy button to drop formatted text straight into your clipboard.

Modern UI: Dark slate developer aesthetic with horizontal and vertical scrollbars for oversized ASCII designs.
